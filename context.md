# Bot Context

## What this project is

This repository contains a WhatsApp group bot for a CSE/department community.
It connects to WhatsApp using the Baileys library, listens for messages, and
responds to supported commands. It is an always-on process, not a hosted HTTP
webhook service.

## What the bot can do

- Send configured academic notices and replies, including text and images.
- Show menus, help, bus schedule images, and study-resource links.
- Start quizzes and show quiz scores in supported groups.
- Run the CSE mini-games `CR hunt` and `CR dig`, show wallets/leaderboards, and
  transfer fictional points between members.
- Fetch G-rated GIFs using the GIPHY API when a key is configured.
- Let authorized moderators and admins update replies, manage resources and
  group access, forward messages, and manage admins.
- Run `.cr <natural-language request>` through the configured Hermes API. Hermes
  can select only a safe, allowlisted bot command; the bot validates the result
  and applies its regular command permissions. It cannot select shell,
  administrative, or other explicitly disallowed commands.

The routine command is currently a placeholder in `bot-data.json`; replace it
with the actual class routine before relying on it.

This version does not schedule announcements, expose an inbound webhook, or
execute free-form responses generated by Hermes.

## Runtime and stack

- **Runtime:** Node.js 18 or newer.
- **Implementation language:** JavaScript, using ECMAScript modules (`"type":
  "module"`).
- **WhatsApp connection:** `@whiskeysockets/baileys`; the bot links as a
  WhatsApp companion device using a QR code.
- **Logging and utilities:** Pino, `qrcode-terminal`, and `@hapi/boom`.
- **Tests:** Node's built-in test runner (`npm test`).
- **Process model:** Run `node index.js` and keep it online with a process
  manager such as PM2 or systemd. The bot reconnects when its WhatsApp
  connection closes, except when logged out.
- **Persistence:** `bot-data.json` stores editable replies, media paths,
  resources, and quiz questions. `bot-state.json` stores mutable game, quiz,
  admin, and group settings. `auth_session/` stores private WhatsApp credentials.

There is no Express/Fastify server or inbound HTTP API. Hermes and GIPHY are
outbound API integrations.

## Languages

There are two meanings of “language” for this bot:

- **Programming language:** JavaScript (ES modules); there is no TypeScript or
  Python application code.
- **Human languages:** Most commands and built-in replies are English. Some
  configured notices contain Bengali (Bangla), alongside English text. The bot
  sends the configured text as written; it does not currently detect a user's
  language, translate messages, or guarantee multilingual Hermes responses.
  Replies can be changed in `bot-data.json`.

## Commands and access

Commands use the `CR` prefix, for example `CR help`, `CR menu`, `CR classtime`,
`CR rsrc`, `CR quiz`, and `CR hunt`. The `.cr <request>` prefix is reserved for
Hermes-backed natural-language selection.

Access varies by command and by the configured Notice, Discussion, and
moderator groups. Bot-admin and moderator-only operations include changing
configuration, managing group/admin access, and running `CR run`. The shell
command feature executes with the operating-system privileges of the bot
process, so only trusted bot admins should have access.

## Configuration and operations

Configuration uses process environment variables; `.env` files are not loaded
automatically.

- `BOT_ADMIN_USER_JIDS`: initial comma-separated admin JIDs, used when bot state
  is first initialized.
- `GIPHY_API_KEY`: enables the GIF command; `GIPHY_TAG` optionally changes its
  tag (default `meme`).
- `HERMES_API_URL`, `HERMES_API_KEY`, `HERMES_MODEL`: configure the
  OpenAI-compatible Chat Completions endpoint for `.cr` requests.
- Notice, Discussion, and initial moderator group JIDs are constants in
  `index.js` and must be configured for the deployment.

Start with `node index.js`, scan the printed QR code in WhatsApp's Linked
devices settings, configure the group JIDs and `bot-data.json`, then restart.
Keep `auth_session/`, API keys, and other credentials private and out of source
control. Review `README.md` for command guides and specific setup details.

## Main files

| File or folder | Purpose |
| --- | --- |
| `index.js` | WhatsApp lifecycle, message parsing, authorization, command dispatch, and reply delivery |
| `hermes-agent.js` | Hermes API client, allowlist construction, and response validation |
| `cse-game.js` | CSE game rules, wallet validation, point transfers, and leaderboard helpers |
| `bot-data.json` | Configured bot replies, images, resources, and quiz questions |
| `bot-state.json` | Runtime state created locally |
| `auth_session/` | Private Baileys login credentials created locally |
| `assets/` | Images sent by bot commands |
| `test/` | Automated tests, run with `npm test` |
